## Interpretation

Diagnosis stayed 9/9 and top hypothesis stayed 7/9 — same as Qwen and the
deterministic baseline. The model is not the diagnoser.

Fix accuracy fell from 5/9 to 2/9, matching the Qwen run. The same three
near-threshold executes dropped below the 0.7 gate:

- `cl-config-missing-secret-006`: 0.703 → 0.659
- `cl-app-unhandled-exception-007`: 0.734 → 0.689
- `cl-app-bad-logic-009`: 0.722 → 0.679

Gemma produced more investigation activity than Qwen (20 useful evidence
requests vs 12; 89/138 accepted vs 81/128) but that extra activity did not
change which cases cleared the gate. Unsafe accepted stayed 0.

This is the same architectural result as the Qwen compare: a larger
instruct model can add candidates without owning diagnosis, and the
deterministic gate still decides execute vs escalate.
